# Termux Development Environment

My personal development environment for Termux.

## Included

- Neovim
- Fish Shell
- Tmux
- nnn File Manager
- fzf
- ripgrep
- fd
- bat

## Features

- Modern Neovim configuration
- Fish shell with custom functions and aliases
- Tmux workflow for terminal productivity
- nnn integration with Neovim
- Fast file searching with fzf and fd
- Powerful text searching with ripgrep
- Clean command-line file previews with bat

## Requirements

- Termux
- Git
- Neovim
- Fish
- Tmux

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/dotfiles.git
```

Copy the configuration files:

```bash
cp -r dotfiles/nvim ~/.config/
cp -r dotfiles/fish ~/.config/
cp -r dotfiles/nnn ~/.config/
cp dotfiles/.tmux.conf ~/
```
